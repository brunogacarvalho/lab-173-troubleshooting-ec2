Lab 173 · Troubleshooting the Creation of an EC2 Instance

Amazon EC2 AWS CLI Diagnóstico

Visão geral

Neste laboratório, foi utilizada a AWS CLI para criar uma instância EC2 e solucionar falhas durante o provisionamento e a inicialização de uma aplicação web. A atividade também envolveu o diagnóstico de conectividade com Nmap e a verificação dos registros de inicialização.

Atividades realizadas

01

Provisionamento via AWS CLI

Execução de script para criação da instância EC2 a partir da máquina CLI Host.

02

Correção de erros

Identificação e correção de falha relacionada ao ID da AMI utilizada na criação da instância.

03

Diagnóstico de rede

Verificação de portas com Nmap e análise dos registros de inicialização da instância.

04

Validação da aplicação

Acesso à aplicação Café e realização de pedidos para verificar o funcionamento do sistema.

Arquitetura e tecnologias
